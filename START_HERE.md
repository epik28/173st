# Самостоятельный старт двух агентов

Открыть одновременно:

- Codex: `/home/andrew/173st/codex`, ветка `codex/verification`.
- Gemini / Antigravity: `/home/andrew/173st/agy`, ветка `agy/development`.

В оба приложения можно отправить **одинаковый запрос**:

> Определи свою роль по текущей ветке: codex/verification — codex,
> agy/development — agy. Для codex прочитай AGENTS.md, для agy — GEMINI.md.
> Затем прочитай TASKS.md и указанные в нём требования и карточки.
> Займи только свой worktree. Через tools/tasks.py next <role> самостоятельно
> выбирай и выполняй доступные задачи своей роли. Соблюдай границы файлов,
> общий контракт и критерии приёмки. После каждой карточки обновляй только
> свой status JSON и handoff, записывай фактические проверки и делай коммит.
> Продолжай следующую доступную карточку без нового запроса.
> Готовность другого агента читай через очередь из его коммитов, без ручной
> передачи SHA и без чтения его незакоммиченных файлов. Если ты codex и доступна
> карточка интеграции, выполни её сам. При ожидании соблюдай TASKS.md.
> Когда доступных задач больше нет, освободи локальную сессию и сообщи результат.
> Не создавай новые этапы вне очереди и не объявляй непроведённые проверки успешными.

## Посмотреть состояние

```bash
python3 tools/tasks.py status
python3 tools/tasks.py next codex
python3 tools/tasks.py next agy
```

Завершённый диалог приложения очередь сама не возобновляет. Если агент остановился
в ожидании, после появления зависимости достаточно написать ему «Продолжай очередь
своей роли по TASKS.md». Пока диалог работает, он может сам перечитывать готовность
в пределах указанного в TASKS.md времени ожидания.

Общие локальные JAR лежат в `../.local/`, сборки и отчёты у каждого worktree отдельные.
RNG-001, RNG-002, CHUNK-001 и NBT-001 приняты. Следующий пакет — REGION-001.
Настройки подтверждений Antigravity: [docs/antigravity.md](docs/antigravity.md).
