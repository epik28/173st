# Antigravity: меньше ручных подтверждений

Проверено по официальной документации 2026-11-07. Названия зависят от версии и
интерфейса; настройки CLI и графического приложения различаются.
Эта памятка не меняет локальные настройки приложения.

## CLI: принимать изменения файлов автоматически

Выполнить `/config`, выбрать **Agent Mode → accept-edits**. Это автоматически
принимает создание и изменение файлов workspace. Запуск команд управляется
отдельной настройкой Tool Permission.

Соответствующий фрагмент `~/.gemini/antigravity-cli/settings.json`:

```json
{
  "agentMode": "accept-edits"
}
```

Добавить ключ в существующий JSON, сохранив остальные настройки.
Для автоматического выполнения команд внутри sandbox: включить Sandbox Mode
и выбрать Tool Permission → `proceed-in-sandbox`.
Для выполнения инструментов без обычных запросов: Tool Permission → `always-proceed`.
Правила `ask`/`deny` продолжают действовать. Artifact Review → `always-proceed`
управляет паузами на артефактах, а не принятием файлов.
Режим `auto`, если доступен, тоже принимает правки и автоматически оценивает команды.

Источник: [CLI settings](https://antigravity.google/docs/settings?tab=cli).

## Графическое приложение

Для планов: **Settings → General → Plan Review Policy → Always Proceed**.
Явный `/plan` всё равно может остановиться для согласования; для работы по готовым
карточкам просить сразу выполнять очередь и продолжать после составления плана.
Источник: [Artifact review](https://antigravity.google/docs/artifact-review).

Для команд: **Settings → Projects → выбрать проект → Permission Preset**.
`Auto` сокращает запросы, сохраняя sandbox; `Turbo` запускает все команды без
изоляции и даёт полный доступ к файловой системе. В предыдущем интерфейсе:
**Terminal Command Auto Execution → Always Proceed**. Настраивать нужный проект
можно отдельно от глобальных настроек. Явные правила разрешений имеют приоритет.
Источник: [Agent settings](https://antigravity.google/docs/agent-settings).

## Запрос агенту

> Продолжай очередь роли agy по GEMINI.md и TASKS.md. Выполняй доступные карточки,
> делай коммит после каждой и переходи к следующей без повторного согласования.
> Исправления по замечаниям Codex внутри текущего контракта выполняй сам.
> После составления рабочего плана продолжай реализацию. Соблюдай границы роли.

Запрос определяет разрешённый объём работы, а подтверждения инструментов задаются
настройками приложения. Очередь не возобновляет уже завершившийся диалог сама.
