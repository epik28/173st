## Результат и границы

Реализовать `setSeed`, `nextInt(bound)`, `nextLong`, `nextBoolean`, `nextFloat`,
`nextDouble` и проверить их вперемешку с прежним `nextInt`. Gaussian, nextBytes,
stream API, генератор мира и новые зависимости не входят в пакет.
Java-эталон вызывает настоящий `java.util.Random`, без ручной реализации LCG.

Rust, в существующем `beta_core::java_random`:

```rust,ignore
pub enum RandomError { InvalidBound }
impl JavaRandom {
    pub fn set_seed(&mut self, seed: i64);
    pub fn next_int_bound(&mut self, bound: i32) -> Result<i32, RandomError>;
    pub fn next_long(&mut self) -> i64;
    pub fn next_boolean(&mut self) -> bool;
    pub fn next_float(&mut self) -> f32;
    pub fn next_double(&mut self) -> f64;
}
```

`RandomError` реализует Debug/PartialEq/Eq; `InvalidBound` при bound≤0 не меняет
состояние. В Java адаптер ловит `IllegalArgumentException` именно этого вызова.
Long должен повторять знаковые промежуточные преобразования Java; bounded int —
включая отбрасывание выборок при переполнении. `set_seed` эквивалентен новому Random
для следующих методов пакета. Нельзя разделять состояния по методам.

## Протокол

Строка входа: `case_id<TAB>seed_i64<TAB>operations`.
Правила ID, комментариев, строго пустых строк, ошибок и LF — как в RNG-001.
`operations` — от 1 до 100000 операций через `;`, без пробелов и пустых элементов;
суммарно не более 100000 операций на вход. Перед каждой строкой новый Random.

| Токен | Метод | Значение в выходе |
| --- | --- | --- |
| `int` | nextInt() | signed i32 decimal |
| `bound:N` | nextInt(N), N — signed i32 decimal | decimal или `invalid_bound` при N≤0 |
| `long` | nextLong() | signed i64 decimal |
| `boolean` | nextBoolean() | `0` или `1` |
| `float` | nextFloat() | raw IEEE-754 bits, 8 lowercase hex digits без префикса |
| `double` | nextDouble() | raw IEEE-754 bits, 16 lowercase hex digits без префикса |
| `seed:S` | setSeed(S), S — signed i64 decimal | `ok` |

Выход: `case_id<TAB>zero_based_index<TAB>operation_name<TAB>value`.
operation_name — `int`, `bound`, `long`, `boolean`, `float`, `double` или `seed`,
без аргумента. Одна запись на операцию, включая invalid_bound и reseed.
Неверный синтаксис, выход аргумента за диапазон или лимит — stderr/nonzero;
`bound:0` и `bound:-1` являются валидными тестовыми операциями с результатом ошибки.
Сравнение точное, float/double по битам, десятичная печать float не используется.
