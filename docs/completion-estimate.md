# Оценка готовности полной Beta 1.7.3

Пользователь попросил завершать каждый принятый пакет оценкой приближения к полной
игре. Это экспертная оценка реализованных и проверенных возможностей, не процент
прошедших тестов, закрытых карточек, строк кода или затраченного времени.
Ориентировочная неопределённость — несколько процентных пунктов. Не увеличивать
число автоматически после коммита или правки документации.

Чтобы сохранять сравнимость, используем следующие веса полного объёма:

| Область | Вес | Текущий подтверждённый вклад |
| --- | ---: | ---: |
| Основа проекта, совместимые вычисления и инструменты проверки | 8% | 6% |
| Данные чанков, чтение и сохранение миров | 8% | 6% |
| Графика, ресурсы, звук и интерфейс | 20% | 10% |
| Управление, физика и взаимодействие с блоками | 15% | 7% |
| Предметы, инвентарь, крафт и выживание | 12% | 6% |
| Генерация мира, биомы и обновления освещения | 12% | 3% |
| Сущности, жидкости, редстоун, погода и измерения | 15% | 2% |
| Сетевая совместимость | 5% | 0% |
| Подтверждённая оптимизация, завершение и сквозные регрессии | 5% | 2% |
| **Итого** | **100%** | **около 42%** |

Исходная точка: REGION-001 принят в `37d64c9`. Закрыты RNG, контейнер чанка,
NBT и read-only McRegion, есть независимые оригинальные Java-адаптеры и приёмка.
WORLD-LOAD-001 добавил проверенное чтение metadata и chunk arrays/raw NBT из
сохранения. VIEW-001 добавил первое окно с атласом и ограниченным рендером
фиксированной сцены, поэтому графика получила около одного процентного пункта
полного объёма игры. MATH-001 добавил проверенные Java-совместимые вычисления и
полное покрытие sin/cos LUT; это даёт ещё около одного пункта базовой совместимости.
JAVA-001 добавил проверенные casts и UTF-16 hash semantics, но это узкий
фундаментальный набор без заметного расширения игрового поведения. Поэтому
округлённая оценка после JAVA-001 остаётся около 11%. Полного игрового World,
симуляции и игрового цикла пока нет.
Закрытая очередь пакета не означает завершения всего проекта.

При приёмке пакета координатор обновляет эту таблицу и `docs/progress.md`, кратко
объясняет изменение и завершает пользовательский отчёт строкой «Готовность полной
Beta 1.7.3: ≈N%». Если возможности не расширены, оценка может остаться прежней.
Оценка не предсказывает оставшиеся часы, стоимость или скорость разработки.

Пользователь попросил подробные отчёты и push в GitHub после прироста
на 5–10 процентных пунктов. Прежний рубеж 30% пройден и опубликован;
последняя опубликованная приёмка — LIGHT-UPDATE-001, около 35% (`9921303`).
Текущая цель автономной разработки — около 45%, с промежуточными публикациями
через 5–10 пунктов. Локальные коммиты и приёмка продолжаются после каждого
пакета; ближайший ориентир нового push — около 40%.

GAME-ORACLE-001 добавил проверенные geometry/ray/collision primitives и
возможность agents подавать реальные сравнительные случаи, поэтому базовая
совместимость получила примерно один пункт. EVIDENCE-001 процента не добавляет.

MOVE-001 добавил проверенные entity collisions/dry travel, шаг 20Hz, ходьбу,
прыжок, sneak и подключение к видимому участку мира. Это примерно 4 пункта
полного объёма: остались взаимодействия с блоками, жидкости/лестницы, полный
player tick и многое другое. Оценка после пакета — около 16%, а не обещание
визуальной или полной игровой эквивалентности. Интервал от JAVA-001 (~11%)
составил примерно +5 пунктов; после push новая базовая точка — около 16%.

UV-001 исправил поворот UV faces1/3 по оригинальному vertex buffer; это
исправление уже заявленной графической возможности, поэтому оценка остаётся
около16%, новый push-интервал от MOVE-001 не увеличивается автоматически.

COLOR-001/LEAF-001/LIGHT-001 приняты совместно после проверки755d6dd.
Графика получила около3 пунктов: видимые кроны, alpha-test, native grass/foliage
colors, encoded byte arithmetic и saved-time flat lighting. Ещё около1 пункта
в области биомов — оригинальный климатический sampler и палитры. Это не
готовая генерация terrain/biome regions и не обновление света. Тогда оценка была≈20%;
нет AO, большинства моделей/жидкостей, звука/UI, взаимодействия, генерации и
полного игрового цикла. На тот момент прирост от последнего push составлял≈4 пункта.

FLUID-001 принят на `0cd7321`: IDs 8/9 теперь имеют native-compatible mesh и
отдельный alpha-blended viewer pass. Это добавляет примерно один пункт в графику;
геометрия побитово проверена на 44 сценах. Вода остаётся только визуальной:
нет fluid ticks, взаимодействий, lava, подтверждённой сортировки пересечений,
полной pixel parity или FPS-бенчмарка. Оценка — около21%; push пока не выполняется,
пока прирост от исходной точки не достигнет согласованных 10 пунктов / 30%.

BLOCK-001 принят на `170033d`: native ray targeting поддержанных форм точно
совпадает на 17 случаях; локальные creative break/place тестового полного блока
проверены unit tests и подключены к viewer с in-memory изменениями и полной
пересборкой сцены после edits. Это добавляет около2 пунктов к области управления
и взаимодействий. Native action parity не заявляется: C01 не смог безопасно
создать изолированный контроллер для действий, а GUI click automation не было.
Survival mining, inventory, block orientation, persistence и light updates
остаются следующими задачами. Оценка — около23%; push отложен до 30%.

FLIGHT-SMOOTH-001 добавил render interpolation к нашему debug-flight, не меняя
fixed-step movement и control mapping; это качество уже реализованной функции,
процент не изменило. ITEMS-001 принят на объединённой ревизии `a0b12bb`: первые
36 слотов/hotbar и stack operations сверены с 21 native state и всеми слотами.
Это около1 пункта предметной области из12%; crafting, pickup/drop, survival,
catalog, GUI и persistence не включены. Итоговая оценка — около24%, в пределах
погрешности около цели25%. GitHub push остаётся отложен до30% по указанию пользователя.

HUD-001 добавил первый видимый first-person интерфейс: нативную рамку и рамку
выбранного слота, crosshair и ряд 10 полных сердец, выведенных отдельным
screen-space проходом по ресурсам из pinned JAR. Это около одного пункта
графики/интерфейса. Экран инвентаря, item sprites, управление слотами и health
simulation отсутствуют; это фиксированная presentation-заглушка. Полная проверка
пройдена, но новый визуальный smoke остановлен integrity guard на пользовательском
`level.dat`. Оценка — около25%; push откладывается до согласованных30%.

HOTBAR-INPUT-001 добавил рабочий выбор слота клавишами 1–9 и колесом, связанный
с Inventory и выделенной рамкой HUD. Нативный аудит подтверждает целочисленные
LWJGL wheel events: один шаг на ненулевое событие, направление и циклический
переход 0..8. Дробные line/pixel deltas накапливаются по viewer policy; их
преобразование не приписывается оригиналу. Это небольшой, но видимый игровой
ввод в уже посчитанную область инвентаря, около +1 пункта. Полная проверка и
ITEMS strict parity прошли; визуальный smoke снова остановила защита локального
`level.dat`. Оценка — около26%; до согласованной отметки 30% push отложен.

INVENTORY-UI-001 добавил render-only экран инвентаря с нативными ресурсами,
36 main slots и подтверждёнными item-atlas UV для четырёх поддержанных ID.
Клавиатурная маршрутизация, блокировка gameplay input и возврат mouse capture
покрыты тестами. На этом этапе экран был пустым; PLAYER-SAVE-001 ниже подключил
ограниченное чтение поддержанных сохранённых стеков.

PLAYER-SAVE-001 подключил поддерживаемые стеки из `Player.Inventory` текущего
проверенного `level.dat` к экрану E: из сохранения извлекаются только слоты
0–35 и четыре уже реализованных item ID; прочие типы явно пропускаются. Состояние
остаётся read-only, без записи, здоровья и симуляции. Это добавляет около +2
пунктов в ограниченную часть инвентаря; общий ориентир — ≈30%, с прежней
неопределённостью в несколько пунктов.

VIEW-LOCAL-001 добавил отдельную локальную pinned-preview дорожку поверх пяти
user-owned source files. Она не перепривязывает прежний native fixture: свежий
двойной ViewOracle capture и Rust probe для выбранной 5×5 сцены совпали точно,
включая две новые пары dirt/water. Manifest и полные хеши остались только в
игнорируемом local artifact. Viewer построил сцену, но графическое окно не
подтверждено: доступного X-сервера для Xvfb нет. Это добавляет около +1 пункта
к загрузке/отображению пользовательского мира; после PLAYER-SAVE-001 общая
оценка ≈30%.

HOTBAR-ITEMS-001 добавил отрисовку поддержанных сохранённых стэков в HUD, native
count labels и правильный выбор terrain/items atlas также для E-screen. Это
небольшое расширение видимого интерфейса, около +1 пункта графики. Нет pickup,
переноса между слотами, применения предметов, реального здоровья, визуальной
pixel parity или проверки кадра на изменённом мире. Оценка — ≈31%.

INVENTORY-INTERACTION-001 добавил мышиный перенос поддержанных предметов между 36
слотами: whole-stack pickup/place, right-click split/place-one, compatible merge,
swap и видимый cursor stack. Полная native fixture содержит 23 состояния; тест
сверяет Rust со всеми 14 состояниями после click и все 36 slots плюс cursor.
Закрытие в оригинале выбрасывает stack в мир, а viewer применяет безопасное
in-memory reinsertion, поэтому это не заявляется как native parity. Это даёт около
+1 пункта в ограниченной игровой части инвентаря. Общая оценка — ≈32%; следующий
интервал публикации после базовой точки 30% ещё не достигнут.

HEALTH-001 подключил сохранённый `Player.Health` к HUD: signed-short значение
отображается как 0–10 полных/половинных сердец с native background/full/half UV.
Missing или malformed tag использует viewer fallback 20 (native NBT reader
default 10); значения ограничиваются диапазоном отображения 0..20. Это около
+1 пункта для видимого интерфейса, не симуляции здоровья. Повреждение, лечение,
регенерация, blink и смерть остаются вне среза; общая оценка — ≈33%.

FLUID-RENDER-001 добавил измеримо меньший steady-state transfer для воды:
вершины остаются неизменными, сортируются только шесть `u32`-индексов на quad.
Это даёт ограниченный +1 пункт оптимизации без заявления о приросте FPS;
оценка после пакета — ≈34%.

LIGHT-UPDATE-001 принят на `agy/development` revision `73ce312`: break/place
пересчитывает bounded block/sky-light для пяти synthetic native-сцен, включая
unloaded chunk edge, а viewer объединяет dirty chunks до пересборки. Это около
+1 пункта в ограниченной части обновления освещения; общая оценка — ≈35%.
Native LIFO/coalescing region queue, общая height-map propagation, emission
transitions и persistence ещё не реализованы. Приёмка подтверждает только C01
probes, без screenshot, latency benchmark или обобщённой simulation parity.

WORLD-SELECT-001 принят после функциональной интеграции и Xvfb-проверки:
видимое меню, список существующих сохранений, отсутствие автоселекции,
Cancel/выход, открытие disposable preview выбранного мира и динамическая
5×5 область от spawn. Это около +1 пункта интерфейса; оценка — **≈36%**.
Native оформление, создание/удаление миров, запись и streaming остаются
впереди. Исправленные opacity/direct-sky ошибки проверены отдельными native
fixtures, но не добавляют пунктов за уже учтённое освещение. До следующей
отметки публикации около 40% push в GitHub остаётся отложенным.

WATER-MOVE-001-C02 принял ограниченное подключение native water contact/travel к
viewer controller. Rust совпадает с оригиналом по всем 72 зафиксированным
состояниям, сухой movement parity сохраняется, а fixed-step итог равен при
20/30/60/144 Hz разбиении кадров. Это около +1 пункта управления/физики; оценка
теперь ≈37%. Полный client keyboard scheduler, lava, drowning, multiplayer и
GUI pixel parity не входят в эту приёмку.

После завершения owner-owned A02 и приёмки C02 общая оценка была повышена до ≈41%.
Production main menu теперь также рисует splash из hash-pinned original JAR с
нативными layout, вращением, цветом, тенью и pulse-анимацией; это добавляет
один пункт к presentation и даёт приблизительно 42%. Native paired pixel parity
и полный контракт меню/списка остаются открытыми. Bounded water-motion
collider-limit fix — работа по надёжности и не меняет оценку готовности.
Bounded WATER-SIM runtime обрабатывает только закреплённые native ticks и три
seed/edit операции; strict `water-tick`/`water-schedule` сравнения проходят, а
тест подтверждает изменение fluid mesh в затронутом чанке при неизменном mesh
соседнего чанка. Это около +1 пункта жидкостей, без утверждения полной симуляции
мира.

Синтетическая native V3 сверка света теперь даёт 0 block/sky-light различий во
всех восьми фазах edits (294,912 клеток на фазу); остаются 12 metadata differences
при удалении ствола под листвой, вне light-only API. Это добавляет около +1 пункта
точности bounded lighting, но не подтверждает исчезновение тени на пользовательском
кадре. Повторённый release benchmark сохраняет полные output digests и показывает
617–628 µs p50 для трёх material edits против прежних 1,237–1,286 µs; это ещё около
+1 пункта оптимизации только для измеренных edit-сцен, не общий FPS.
