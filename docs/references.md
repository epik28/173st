# Источники

Оригинальная Minecraft Beta 1.7.3 — эталон игрового поведения. Клиентский JAR найден
в кэше PrismLauncher и подготовлен локально. Серверный JAR пока не подготовлен.

- Версия инстанции по `mmc-pack.json`: `b1.7.3`.
- Клиент SHA-256: `af1fa04b8006d3ef78c7e24f8de4aa56f439a74d7f314827529062d5bab6db4c`.
- Клиент SHA-1: `43db9b498cb67058d2e12d394e6507722e71bb45` — совпадает с локальными
  метаданными PrismLauncher для оригинального артефакта Mojang.
- В архиве 747 `.class`, исходников `.java` нет; есть `terrain.png`, `gui/items.png`
  и другие ресурсы. Декомпиляция/подготовка Java-адаптеров пока не выполнена.
- Локальная рабочая копия: `.local/minecraft/client-b1.7.3.jar`; сведения о
  происхождении и runtime: `.local/minecraft/manifest.json`.

Локальные пути задаются в `config/local.toml`. В подготовленной раскладке исходники
для исследования находятся в `.local/reference-sources/`, wiki — во внешней папке.
Наличие локального клона не означает включение его кода в проект.

В проверенном `mc173` есть незавершённые детали движения и игровой логики.
В проверенном C++-сервере воспроизведена ошибка диапазона `next_float()` при seed 42;
генератор описан как ландшафт в стиле Beta. Ни один из этих серверов не использовать
как единственный источник ожидаемых результатов.

При повторном исследовании фиксировать актуальный commit. При заимствованиях
записывать точные файлы, лицензию и необходимые уведомления отдельно от этого списка.
